# Software tool icons

Icons identify tools used in the portfolio. Product names and marks belong to their respective owners. Assets are served locally; the SVG path data is unchanged.

React Native reuses the existing React mark. Vite reuses the existing Vite asset. Monochrome marks are displayed in white for contrast with the dark gallery wall. Codex uses the Codex mark from Lobe Icons.
